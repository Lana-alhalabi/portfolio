ASSETS FOLDER — LANA PORTFOLIO
================================

Place your files here:

CV / Resume
-----------
  lana-cv.pdf         → Your CV PDF. Once added, the "Download CV" button works automatically.

Project Screenshots
-------------------
  project-1.png       → Screenshot for project card 1 (Web Dev)
  project-2.png       → Screenshot for project card 2 (Design)
  project-3.png       → Screenshot for project card 3 (Web Dev)
  project-4.png       → Screenshot for project card 4 (Other)

  Recommended size: 1200×675px (16:9 ratio) for best results.

Profile Photo (optional)
------------------------
  lana-photo.jpg      → Your photo (if you want to replace the monogram in About).
                         See the comment in index.html inside .about-avatar-frame.

Open Graph Image (optional)
----------------------------
  og-image.png        → 1200×630px image shown when sharing your link on social media.

NOTES
-----
- Keep filenames lowercase, no spaces (use hyphens).
- PNG or JPG both work for screenshots.
- This folder is already referenced in index.html and style.css;
  just drop files here with the exact names above.
